How this works. The directory is generated automatically from publication records in OpenAlex. A paper counts as animal welfare research if it appears in a core welfare journal, or if its title or abstract matches welfare-related terms. Institutions and researchers are taken from the authors' affiliations on those papers. "Papers" = number of matching papers since 2010.

Because this is automated, some entries will be incomplete or wrong (e.g. outdated affiliations or merged names).
